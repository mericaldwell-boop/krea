# Crew Roles shirt designs

Four roles (Captain, First Mate, Deckhand, Crew), each in two colorways.

| File | Use |
|---|---|
| `*_light-shirts_BASE.png` | Print file for white, sand and light pastel shirts. Has the emblem and role only, with room underneath for the name and year. |
| `*_dark-shirts_BASE.png` | Print file for navy, black and dark heather shirts. It has a cream outline so the ship stays visible on dark fabric. |
| `*_SAMPLE.png` | Example with "THE SMITH CREW · CRUISE 2027", for Etsy mockups and listing photos only. |
| `.svg` | Editable vector versions of every file. |
| `preview-all.png` | All eight designs on light and dark backgrounds. |

All PNGs are 4500 × 5400 px with a transparent background, which matches Printify's print area for t-shirt fronts.

## Adding the buyer's name and year in Printify
Upload the BASE file, then add two text layers under the artwork in Printify's editor:
1. `THE [NAME] CREW`: bold sans-serif (Montserrat ExtraBold or similar), all caps, wide letter spacing. Use navy `#1D3557` on light shirts and cream `#FAF3E0` on dark shirts.
2. `• CRUISE [YEAR] •`: the same font at about 60% of the size. Use teal `#2A9D8F` on light shirts and yellow `#F9C74F` on dark shirts.

For each order, edit those two text layers to match the buyer's personalization before approving the order.
