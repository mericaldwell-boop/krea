## Attributes (same for all 3 listings)
Fill in every one Etsy offers. Each is a free search filter you can show up under.

| Field | Choose |
|---|---|
| Category | Clothing → Gender-Neutral Adult Clothing → Tops & Tees → T-shirts |
| Primary color / Secondary color | Your main photo's shirt color (e.g., Pink, Blue) |
| Occasion | Vacation (or Birthday if offered for Girls Trip) |
| Holiday | Leave blank |
| Sleeve length | Short sleeve |
| Neckline | Crew neck |
| Style | Retro (Family Cruise, Girls Trip) / Minimalist (Cruise Crew) |
| Theme | Travel / Beach & tropical |
| Personalization | ON (paste the instructions above), Required |
| Who made it | Another company or person → Printify |
| What is it | A finished product |
| When was it made | Made to order |
| Shop section | Cruise Crew / Girls Trip / Family Cruise |

## Before you save
- [ ] Check the Family Cruise personalization instructions match how your Printify text is set up (last name only vs. the full "The Smith Family").
- [ ] Check that "Buy 6+ save 10%" is actually set up under **Marketing → Sales and discounts**. If not, delete that section from the descriptions.
- [ ] If your print provider's production time differs, update "2–5 business days."
