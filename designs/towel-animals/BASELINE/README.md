# Towel Animal Family Designs: Baseline Kit

Use this kit to rebuild the 4 towel-animal designs (Dad elephant, Mom swan, Kiddo monkey,
Grandma turtle) at full print quality in Canva or Photopea. The current files
(`../preview_*.png`) are only 1500 × 1700 and print soft, so treat them as **reference only**.

## Files in this folder

| File | What it is |
|---|---|
| `LAYOUT-GUIDE_4500x5400.png` | Full-size canvas with a box for every element, plus the sunset circle in place |
| `LAYOUT-GUIDE_with-current-design.png` | Same guide with the current Dad design faded underneath, so you can match it |
| `sunset-circle_2460px.png` | Clean, sharp sunset circle (transparent PNG), ready to drop in |
| `baseline_dad-elephant_4500x5400.png` (and `_mom-swan`, `_kiddo-monkey`, `_grandma-turtle`) | One file per animal at full canvas size, transparent, with the **name area left empty**. The art is the current low-res design enlarged: a placement reference to redraw over, not final art |
| `baseline_*_GUIDE.jpg` | Same, on white, with a box showing where the personalized name goes |
| `sunset-circle.svg` | Same circle as a vector, so it can be scaled to any size with no blur |

## Canvas

- **4500 × 5400 px**, transparent background, export as **PNG** (Canva: *PNG + Transparent background*).
- That's the Printify tee print area, so one file works for the shirt. I'll make the sticker version from it.

## Layout (px on the 4500 × 5400 canvas)

| Element | Position | Size |
|---|---|---|
| Title "Family Cruise" | centered, top ≈ 450 | ≈ 4360 wide × 920 tall |
| Year "2027" | centered, top ≈ 1350 | ≈ 1000 × 300 |
| Sunset circle | center (2250, 3024) | 2460 wide; bottom cut flat at y ≈ 3957 |
| Towel animal | centered on the circle, top ≈ 1650 | up to ≈ 2700 × 2700; can overlap the circle's bottom edge |
| Personalized name | centered, top ≈ 4470 | ≈ 360 tall, up to ≈ 4000 wide. **Leave empty in your file.** It's added as a Printify text layer (shirts) or per order (stickers) |

The gaps between stripes are **transparent** (the shirt shows through), not white.

## Fonts (closest matches; use your favorites)

- **Title:** a bold retro script with a navy drop shadow offset down-right. Closest free match: *Pacifico*.
- **Year and label:** a bold geometric sans in all caps with wide letter spacing (about 300). Closest: *Montserrat ExtraBold*.

## Towel animals

- Redraw or regenerate each animal at **at least 2700 px** tall, on a transparent background.
- Keep the same style: white towel texture, navy outlines, pink cheeks, plus one accessory each (Dad: aviator sunglasses; Mom: hibiscus flower; Kiddo: life ring; Grandma: tropical drink).
- Export each animal as its own PNG first (easy to reuse), then the full design.

## When you're done

Save each finished design as e.g. `towel-animal_dad_4500.png` (and `_mom`, `_kiddo`, `_grandma`, plus
any extras like `_grandpa`) and send them to me or upload them to Printify. I'll make the shirt mockups, the sticker
files and the listings from them.
